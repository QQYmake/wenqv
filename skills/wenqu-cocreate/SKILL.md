# 问渠逐级共创

## 前置检查

读取当前 conversation 所拥有训练的 current.md 和 stage_v1.md。必须存在 INTAKE_DONE，mode 必须为 deep，completed.cocreate 必须为 pending。条件不满足时路由到 wenqu-intake；fast 模式不加载本 Skill。

## 工作流

按顺序完成两个环节，每次只推进一个。每个环节先给：

- 自行输入
- 我不知道，求推荐

只有用户选择推荐时才生成 ABC。每套方案包含方案名称、核心设计、适用情况、优势、风险和实施条件，只标一个更推荐，允许用户选择、修改或组合。

1. 教学目标与重点难点合并为一个问题：
   - 目标和重难点必须同时确认，并显式说明三者的递进关系：教学目标是学生学完能做到什么的终点；教学重点是为达成目标必须掌握的核心知识与技能；教学难点是学生达成目标路上最容易卡住的理解或迁移障碍。目标决定重难点，重难点逐级支撑目标。
   - 目标方向：A 概念理解与基础技能 / B 思维过程与方法探究 / C 应用迁移与核心素养。
   - 重难点方向：A 教材知识结构 / B 学生错误与理解障碍 / C 迁移应用与学科思维。
   - 确认时做相互比较：每个重点都要能落到某个目标上，每个难点都要对应阻碍哪个目标的达成；不允许目标与重难点互相脱离或简单重复。
2. 教学过程与核心问题链合并为一个问题：
   - 必须显式指出二者联系：教学过程是达成目标和突破重难点的时间线；核心问题链是嵌入时间线的关键提问，应沿过程的关键节点推进，而不是一套独立问题。
   - 过程方向：知识建构 / 错误辨析 / 真实任务与迁移。
   - 问题链方向：支架型 / 诊断型 / 迁移型。
   - 确认时要求问题链落到具体环节，至少标出导入、展开、小结或迁移中的对应核心问题。

所有方案必须结合当前课题、学情、情境、课型和时长动态生成。英语阅读、听说、语法、词汇、写作课不可套用同一流程。

## 落盘

每次确认后用 edit 追加或更新 stage_v1.md 的“逐级共创”章节。两个环节完成后写入：

    <!-- COCREATE_DONE -->

再将 current.md 的 cocreate 设为 done，current_skill 设为 wenqu-draft，更新 updated_at，直接进入 wenqu-draft，不再询问。

## 约束

- 用户自行输入时不要强行给 ABC。
- 不替用户强制决定。
- 不生成完整教案。
- 写入前再次确认 owner_conversation_id。
