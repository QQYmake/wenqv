# 问渠逐级共创

## 前置检查

读取当前 conversation 所拥有训练的 current.md 和 stage_v1.md。必须存在 INTAKE_DONE，mode 必须为 deep，completed.cocreate 必须为 pending。条件不满足时路由到 wenqu-intake；fast 模式不加载本 Skill。

## 工作流

按顺序完成五个环节，每次只推进一个。每个环节先给：

- 自行输入
- 我不知道，求推荐

只有用户选择推荐时才生成 ABC。每套方案包含方案名称、核心设计、适用情况、优势、风险和实施条件，只标一个更推荐，允许用户选择、修改或组合。

1. 教学目标：
   - A 概念理解与基础技能
   - B 思维过程与方法探究
   - C 应用迁移与核心素养
2. 教学重点与难点：
   - A 教材知识结构
   - B 学生错误与理解障碍
   - C 迁移应用与学科思维
3. 教学准备：
   - A 低技术普通课堂
   - B 课件、图表、实物或动态演示
   - C 学习单、真实语境或探究资源
4. 教学过程与核心问题链必须分成两个问题：
   - 过程方向：知识建构 / 错误辨析 / 真实任务与迁移
   - 问题链：支架型 / 诊断型 / 迁移型
5. 板书与作业：
   - 板书：知识结构 / 问题推进 / 正误对比
   - 作业：基础巩固 / 纠错变式 / 迁移任务

所有方案必须结合当前课题、学情、情境、课型和时长动态生成。英语阅读、听说、语法、词汇、写作课不可套用同一流程。

## 落盘

每次确认后用 edit 追加或更新 stage_v1.md 的“逐级共创”章节。五个环节完成后写入：

    <!-- COCREATE_DONE -->

再将 current.md 的 cocreate 设为 done，current_skill 设为 wenqu-draft，更新 updated_at，并询问是否生成第一版教案。

## 约束

- 用户自行输入时不要强行给 ABC。
- 不替用户强制决定。
- 不生成完整教案。
- 写入前再次确认 owner_conversation_id。
